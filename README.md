# PulseFit Landing Page

## TechMaster Academy - Phase 1 - Sprint 1

PulseFit is a responsive marketing landing page for a fictional smart fitness tracker.

The product tracks:

- Heart rate
- Sleep
- Daily activity
- Fitness progress

## Project Goal

The goal of the landing page is to communicate the value of PulseFit and encourage visitors to pre-order the product or join the waitlist.

## Target Audience

Health-conscious young adults aged 18–35 who are interested in fitness technology.

## Technologies Used

- HTML5
- CSS3
- JavaScript ES6
- Flexbox
- CSS Grid
- Intersection Observer API
- Font Awesome
- Google Fonts

## How to Run

1. Open the project folder in Visual Studio Code.
2. Install the Live Server extension.
3. Open `index.html`.
4. Right-click the file.
5. Select "Open with Live Server".
